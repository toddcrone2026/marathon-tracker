🍎 Apple Watch Auto-Sync

Set this up once and every run from your Apple Watch syncs automatically.

1
Open the Shortcuts app on your iPhone → tap + → name it Log Run
2
Tap Add Action → search Find Health Samples → Type: Workouts, filter Workout Type = Running, Sort by Start Date newest first, Limit 1
3
Add action: Get Details of Health Samples → Total Distance → unit Miles → save as Miles
4
Add action: Get Details of Health Samples → Duration (seconds) → save as DurSecs
5
Add action: Calculate → DurSecs ÷ 60 → save as TotalMins
6
Add action: Calculate → TotalMins ÷ Miles → save as Pace
7
Add action: Get Details of Health Samples → Start Date → format yyyy-MM-dd → save as RunDate
8
Add action: Get Contents of URL → Method: POST → URL:
Headers: Content-Type → application/json
Body (JSON):
{"fields":{"userId":{"stringValue":""},"date":{"stringValue":"[RunDate]"},"miles":{"doubleValue":[Miles]},"mins":{"doubleValue":[TotalMins]},"pace":{"doubleValue":[Pace]},"feel":{"stringValue":""},"notes":{"stringValue":"Synced from Apple Watch"},"source":{"stringValue":"apple_watch"}}}
9
For automatic sync: Automation tab → New Automation → Workout → Ends → Running → Run Log Run → turn off Ask Before Running
